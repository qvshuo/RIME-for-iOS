# 修改记录

## 2.0.1（18）

修复 WebDAV 部署模块未注册导致同步失败的问题；补齐自定义短语上传，保持仅同步 luna_pinyin_extended.userdb.txt 与 custom_phrase.txt。保存前检查键盘完全访问，连接测试限时 15 秒，网络不可用时及时报错并保留草稿；已保存且未修改时禁用保存按钮。

主应用增加与输入法状态一致的联网状态和系统设置入口。同步进度及结果只显示在同步按钮；日志、同步页左上按钮直接返回键盘，微调同步/导出按钮高度和候选箭头大小。展开前补齐候选，惰性网格持有行快照，减少展开过程的重复布局与潜在越界。

清理未使用声明、旧菜单分支和冗余注释，测试辅助颜色计算移到测试目标。44 项核心测试、运行 UI 检查及设备 Release 构建通过；使用安装 ID test 的真实 WebDAV 合并、上传与回读验证通过。真机网络授权弹窗和全部闪退原因仍需真机验证。

## 2.0.0（16）

更名为 RIME for iOS，统一工程、目标、模块、目录、bundle/App Group 标识及运行时文件命名。注释只保留关键契约与实现原因；测试按领域组织并合并重复情形。更新安装、架构、测试和上游比较文档。

新标识符需要重新启用键盘、填写同步配置。先同步旧键盘，再从新键盘同步恢复词库。librime 保持 1.16.0。后续整理中按 Squirrel 1.1.2 发布包对齐 Lua/octagram 插件提交，重编译全部两平台依赖；增强词库更新至 2026-09-27 并重新部署。

同一版本内取消布局标签渐变；统一系统字体、内容卡片与原生 Liquid Glass 控件。日志导出居中到底部、去除页脚及分享外层导航栏；同步输入行移除特殊底色。补上字段身份隔离、后台快照代次和隐藏期日志暂停；清理脚本重复代码，增加源码/二进制依赖校验。版本仍为 2.0.0（16）。

日志、同步与分享统一为 480 pt；同步补充图标，导出与同步按钮同尺寸同底边。取消字符预览渐入渐出，状态消息放在同步操作栏上方，保持按钮底边稳定。

符号返回字母页时键位与 Shift 图标即时更新，移除大小缩放。同步的服务器、用户名、密码标记红色星号；目录与安装 ID 可留空使用默认值。

## 1.2.0（15）

空格确认混合预输入，不附加空格。菜单只显示其他页面并与 q 对齐。日志自动每秒更新，只保留导出，移除清空。同步字段上下分行，增强对比和顶部留白，明确删除凭据。分享界面临时扩大键盘区域，关闭后恢复。69 项回归及 4 项临时宿主 UI 测试通过。
