# 修改记录

## 2.0.0（16）

更名为 RIME for iOS，统一工程、目标、模块、目录、bundle/App Group 标识及运行时文件命名。注释只保留关键契约与实现原因；测试按领域组织并合并重复情形。更新安装、架构、测试和上游比较文档。

新标识符需要重新启用键盘、填写同步配置。先同步旧键盘，再从新键盘同步恢复词库。此版本没有升级 librime 或改变随包词典。OpenCC 仍为 1.1.9，仅重新编译两个切片以移除旧机器构建目录，后续脚本使用中性相对数据路径。

## 1.2.0（15）

空格确认混合预输入，不附加空格。菜单只显示其他页面并与 q 对齐。日志自动每秒更新，只保留导出，移除清空。同步字段上下分行，增强对比和顶部留白，明确删除凭据。分享界面临时扩大键盘区域，关闭后恢复。69 项回归及 4 项临时宿主 UI 测试通过。

## 1.1.7–1.1.9

修复大写组合与数字/标点提交顺序、扩展内禁用确认弹窗、静态 Lua/octagram 插件加载及日志无界增长。取消候选滚动边缘模糊，改为独立同步/日志页和字段内编辑。引入手动 Shift 后的混合字面组合；其空格语义在 1.2.0 调整为确认。

## 更早版本

建立直接 librime 桥、预构建数据和自研 SwiftUI 键盘；WebDAV 文件编排与传输分离，补齐路径验证、失败清理、维护互斥和会话归属。主应用收敛为设置状态入口，配置、同步和日志在键盘完成。
